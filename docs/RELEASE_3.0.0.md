# DJAI 3.0.0 release notes

DJAI 3.0.0 integrates the remaining automatic-product phases on top of the 2.2 render-and-measure engine.

## Product

- listener-first upload -> progress -> playback UI;
- optional Pro workspace;
- finished-set browser player;
- prepared live-stream player;
- lightweight feedback.

## Automatic delivery

- expanded measured retry;
- later-cue/alternative retries;
- last-resort native quick cut;
- no routine confirmation in default mode;
- internal fallback evidence retained.

## Stems

- automatic off/background/wait policies;
- dedicated background stem worker pool;
- stem-derived vocal/bass cue evidence;
- stem-aware measurements and DSP.

## Learning

- grouped cross-validation;
- confidence-scaled learned authority;
- automatic measurement ingestion;
- genre-pair submodels;
- automatic periodic refit;
- per-listener profiles and implicit events.

## Set intelligence

- balanced, smooth, build, warm-up, peak, and sunset energy curves;
- set-order objective includes curve fit and listener preference.

## Live

- deterministic prepared-plan streaming;
- now/next manifest;
- source prefetch;
- progressive MP3 endpoint.

## Compatibility

The Pro API/CLI, immutable-plan validation, sample-identical previews, manual order, and detailed rating workflow remain available.
